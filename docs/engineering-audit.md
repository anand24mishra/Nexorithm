# Engineering audit — 2026-10-25

Source baseline: clean working tree. Backend/src/index.ts constructs JudgeService in the HTTP process. SubmissionService awaits all tests before persisting, and returns 200. executorFactory uses execSync and writable host /tmp; no network, process, filesystem or memory isolation. Python selects the last alphabetical Solution member; JavaScript discovers names from user code and strips all whitespace from JSON. Judge compares trimmed output before checking exit status, allowing crashing programs to pass.

Tests are embedded in seedProblems and Mongo Problem records, with external imports often having no authoritative tests. Problem detail filters hidden tests, but daily-challenge response does not. Mongo submissions have only terminal verdicts, no queue state; mock submissions are process-local. History is unpaginated, scoped to an optionally authenticated user that defaults to shared anonymous. JWT verification has no algorithm/payload restrictions; development secret is the default in every environment. Google tokens are verified server-side; frontend persists bearer tokens in localStorage. Passwords use bcrypt. Existing dashboard reads submission repositories and depends on display-format verdict strings.

Frontend has a reducer context, synchronous submit hook, Monaco, two workspace implementations, and history hooks. Run and Submit both persist submissions. Preserve this behavior, display verdict strings, existing layouts, JWT response contract and OAuth entry points. No automated tests are configured. Queue files are empty. Compose contains only a frontend image; backend Dockerfile is a single-stage build. Existing workflows build/push without comprehensive checks. k6 exercises HTTP requests and does not establish completed judge throughput. README and diagrams describe features beyond source evidence.

Baseline verification: backend npm run build PASS; frontend npm run build PASS; frontend npm run lint FAIL (14 errors, 6 warnings: effect state updates, mixed context exports, OAuth any types). Docker CLI available but daemon unavailable at the configured macOS socket. k6 available. No baseline backend tests exist. Environment file values were not printed or copied.

Compatibility: async POST intentionally changes 200/final result to 202/id; authenticated submissions become mandatory; durable MongoDB and Redis required for submissions. Existing terminal records remain readable. Function names must come from authoritative metadata/starter contracts, never submitted-code discovery. Linked-list/tree object adapters are not currently implemented and must not be implied by language support.
